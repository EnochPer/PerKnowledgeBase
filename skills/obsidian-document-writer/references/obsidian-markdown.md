# 当前知识库的 Obsidian Markdown 参考

## Properties 示例

```yaml
---
title: ICP 中只优化旋转的 RPY 与 SO(3) 李代数实现
date: 2026-09-22
tags: [ICP, Ceres, SO(3), 李代数, RPY, 位姿优化]
---
```

创建或用户明确要求补 properties 时，按当前文档内容生成 `title`、创建日期和短标签；不要复制示例的主题标签。

## 目录映射

- `00-Inbox`：未整理输入和临时记录。
- `01-Papers`：论文、综述、翻译和阅读笔记，可与图片/PDF 同目录。
- `03-Knowledges`：跨项目可复用的技术知识。
- `04-JobLogs`：具体项目、设备或故障的过程记录。
- `05-life`：生活和个人学习主题。

## 链接与附件

优先使用相对路径：

```markdown
[五度圈](音乐/五度圈.md)
```

如果需要 Obsidian 的模糊链接和反向链接，可以使用 `[[五度圈]]`；关键资料不要只存在插件视图中。附件使用相对路径，避免绝对路径和设备专用路径。

## 内容质量检查

- YAML 能被解析，且 frontmatter 在文件开头。
- 一级标题不重复；正文标题层级连续。
- 公式、代码块和表格闭合。
- 相对链接目标存在，或明确标为待补链接。
- 事实、推断、建议和待验证事项没有混在同一语气中。
- 不把未验证的插件行为、同步成功或性能提升写成确定事实。
