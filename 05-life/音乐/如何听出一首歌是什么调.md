# 如何在没有乐谱的情况下听出一首歌是什么调

这里的“听出是什么调”，通常不是一次听出所有和弦，而是先找到这首歌的**调中心**：哪一个音听起来最像“家”、最适合停下来。确定了这个音，再判断它使用的是大调、小调，或 blues 中常见的混合音阶。

## 先分清几个概念

- **主音（tonic）**：听感上的“家”。旋律和乐句常常在这里获得稳定感。
- **调中心**：围绕主音组织的音高体系。例如“C 大调”的调中心是 C，“A 小调”的调中心是 A。
- **调号**：乐谱开头用升降号表示的一组记号。调号本身不能单独决定实际调性，因为同一组调号可能对应关系大小调。
- **音域**：歌曲唱得高还是低。音域高低不是调性；同一首歌可以整体移调而保持旋律关系不变。

## 一套实际可用的听调流程

### 1. 先找“最像终点”的音

播放歌曲，在每个乐句结尾和整首歌结束处暂停，心里哼一个能让句子“落地”的音。然后在钢琴、键盘或手机调音器上逐个试音：

1. 先哼出自己认为的“家”；
2. 在乐器上找与它同高的音名；
3. 播放这个音，判断它和歌曲是否稳定融合；
4. 如果听起来还想继续走，换相邻音再试。

歌曲最后一个和弦通常提供很强的线索，但流行歌有时会在最后停在非主音和弦、使用淡出，或用悬挂和弦制造开放感，因此不能只依赖最后一个音。

### 2. 判断大调还是小调

找到候选主音后，比较它上方的三度：

- 主音上方大三度，整体常有明亮、开阔的感觉，倾向于大调；
- 主音上方小三度，整体常有暗、紧张或忧郁的感觉，倾向于小调。

不要只听一两个旋律音。流行歌经常使用借用和弦、布鲁斯音、旋律小调等写法，最好结合副歌落点、低音走向和反复出现的和弦一起判断。

### 3. 用低音和和弦验证

低音通常比高音旋律更容易暴露调中心。重点听：

- 贝斯反复回到哪个音；
- 哪个和弦听起来最稳定；
- 哪个和弦离开后会产生“想回去”的感觉；
- 副歌和主歌是否共享同一个中心。

如果能扒出几个和弦，可以观察它们是否围绕某个主和弦组织。例如经常出现 `C–F–G–C`，C 很可能是主音；但 `Am–F–C–G` 既可能听作 C 大调，也可能听作 A 小调，仍需根据旋律的落点和终止感决定。

### 4. 在乐器上做“半音试探”

先选一个候选音作为主音，播放它并同时播放歌曲片段：

- 若音符大多稳定，且句末回到它很自然，候选方向可能正确；
- 若总有明显冲突，向上或向下移动一个半音继续试；
- 找到主音后，再试大调和小调音阶，观察哪一种与旋律冲突更少。

这是一种“先猜、再验证”的方法，比试图一次记住整首歌的所有音高更容易练习。

## 流行歌中容易误判的情况

### 关系大小调

C 大调和 A 小调使用相同的白键，但调中心不同。判断时不要数“用了几个升降号”，而要听：

- 旋律是否经常回到 C 还是 A；
- 终止是否落在 C 大和弦还是 A 小和弦；
- 是否出现 G♯，它常常强化 A 小调的属功能。

### 变调和副歌抬高

有些歌曲在桥段或最后副歌整体升高半音或全音。前后分别找主音即可，不要强行用一个调解释整首歌。若旋律关系保持不变、所有音一起移动，就是移调；若和弦功能或中心发生改变，则可能是更复杂的转调。

### 旋律从非主音开始

歌曲开头的第一个音不一定是主音。前奏也可能故意从属和弦、下属和弦或经过音开始。应优先听完整乐句和副歌的收束位置。

### 伴奏循环没有明确终止

现代流行歌常用四和弦循环，循环本身可能不在主和弦结束。此时同时参考人声旋律、贝斯最低音和整首歌的情绪重心，必要时把循环单独截出来反复听。

## Blues 要怎样判断

Blues 常见的 12 小节进行以 I、IV、V 级和弦为骨架。比如在 C 中，常见骨架是 C7、F7、G7。听 blues 时可以：

1. 找贝斯或吉他反复回到的根音，通常是 I 级；
2. 数 12 小节的分句，观察第 1 小节和第 12 小节的回归感；
3. 在低音中寻找相隔纯四度和纯五度的另外两个根音；
4. 用这三个根音验证 I–IV–V 关系。

Blues 里大三度、小三度、降七度可能同时出现，旋律还会使用蓝调音。因此“听起来有小调味”不等于它就是小调；例如 C7 进行上唱出降 E，仍可能属于 C blues，而不是 C 小调。实际标注时可以说“C blues”“C mixolydian 色彩”或“以 C 为中心”，不必强行归入纯大调/小调。

## 没有乐器时的练习方法

- 用手机录下歌曲最后一个音，循环播放并跟着哼，直到自己的声音与它融合；
- 暂停歌曲，在脑中补唱“回家音”，再重新播放检查是否吻合；
- 听低音线，只记录每个和弦根音的大致高低，不急着判断音名；
- 先用任意音节唱出主音到旋律音的相对距离，再尝试在键盘上找绝对音名；
- 每次只练 8–16 小节，确认后再扩大到整首歌。

调音器或钢琴的作用是把你听到的音高**命名**，不是替你判断调中心。先凭听感找到“家”，再查它是 C、D♭ 还是其他音，耳朵会进步得更快。

## 固定调与首调

### 首调（movable-do）

首调把 `do` 视为当前调的主音：在 C 大调中 C 是 do，在 D 大调中 D 也是 do。它训练的是音级功能和相对音高，适合听出“主音—属音—下属音”的关系，也适合扒旋律和分析和弦功能。

### 固定调（fixed-do）

固定调把 do、re、mi 固定对应 C、D、E 等音名，不随调性改变。它训练的是实际音名识别，适合读谱、记谱和快速说出实际音高；这不等于天生具备绝对音感。

### 两者如何配合

听歌判断调性时，通常先用首调思维：找到 `do`，确认旋律的级数关系；之后再用固定调把 `do` 命名为 C、D 或其他音。这样既不会把“音名记错”误认为“调中心听错”，也能逐步建立绝对音高参照。

可以按下面顺序练习：

1. 听一小段，哼出主音；
2. 判断主音到旋律音是几级或相隔多少度；
3. 用乐器确认主音的实际音名；
4. 写下“调中心 + 大调/小调/blues 色彩”；
5. 最后再核对网上的和弦谱或原调标注。

网上标注的“原调”有时是演奏版本、变调夹位置或歌手现场移调后的结果。真正有用的判断是：这段录音里哪个音承担了稳定中心，以及旋律和和弦如何围绕它运动。
