# 五度圈：从调的关系到 blues 口琴选调

五度圈把十二个音按**相隔纯五度**的关系排成一圈。对 blues 口琴演奏者，它最直接的用途是：**找 I–IV–V 和弦、判断把位、根据歌曲调选择口琴。** 以下口琴说明针对标准大调 Richter 十孔口琴。

![](https://pic1.zhimg.com/v2-8fde9a42d183f0ae895f98ce3599b9b4_r.jpg?source=2c26e567)

## 1. 五度圈为什么这样排列

纯五度包含 7 个半音。例如从 C 向上数 C、D、E、F、G，是纯五度；从 G 再向上纯五度得到 D。沿通常画法的顺时针方向依次是：

```text
C → G → D → A → E → B → F♯/G♭ → D♭ → A♭ → E♭ → B♭ → F → 回到 C
```

这里表示的是音名关系，不要求演奏时一直往高音走。十二平均律下，忽略八度、把等音视为同一个音高类别，走十二步就回到 C；所以能围成一个圈。反方向走则是向上纯四度，也可以理解为向下纯五度。

它也揭示调号关系：从 C 大调出发，顺时针走到 G、D、A，大调调号依次是 1、2、3 个升号；逆时针到 F、B♭、E♭，依次是 1、2、3 个降号。跨到等音调时会换一种拼写，不能把升号无限累加。**圈上相邻的两个大调共享六个音**，因此关系接近。

## 2. Blues 的 I–IV–V 就在主调两边

先找到歌曲主音 I：**左邻（逆时针一步）是 IV，右邻（顺时针一步）是 V。** 罗马数字表示和弦根音相对主音的级数。

```text
五度圈局部： C  →  G  →  D
以 G 为主音：IV     I     V
```

因此 G blues 常见的三个和弦是 **G7、C7、D7**。这里的 `7` 表示属七和弦的结构，不表示整首歌转到了别的调；大调色彩的 blues 经常让 I、IV、V 都使用这种结构，而不是严格套用普通大调的自然和弦。

一个便于练习的 12 小节 G blues 版本如下，每格一小节：

```text
| G7 | G7 | G7 | G7 |
| C7 | C7 | G7 | G7 |
| D7 | C7 | G7 | D7 |
```

最后的 D7 引向下一轮 G7；实际歌曲也可能有第 2 小节提前到 IV、不同结尾或更复杂的替代和弦。小调 blues 的和弦性质又有所不同。**五度圈帮你找根音关系，不能单凭它决定整首歌的和弦性质和顺序。**

## 3. 口琴把位：从琴调沿五度圈数位置

从琴壳标注的调开始，当前位置算第一把位，每顺时针走一步，把位增加一：

| 手持 C 调琴 | 五度圈走法  | 演奏主音 | 常用主音孔位     |
| ----------- | ----------- | -------- | ---------------- |
| 第一把位    | 留在 C      | C        | 1 吹、4 吹、7 吹 |
| 第二把位    | C → G      | G        | 2 吸、3 吹、6 吹 |
| 第三把位    | C → G → D | D        | 1 吸、4 吸、8 吸 |

**把位不是孔号，也不会改变簧片的音高。**C 调琴的 4 孔吸音一直是 D；用一把位时它是二级音，用二把位时是五级音，用三把位时才是主音。[Lee Oskar 把位表](https://leeoskarharmonicas.com/major-diatonic-key-chart/)

### 为什么 blues 常用第二把位

用 C 调琴演奏 G blues 时，2 孔吸音就是主音 G，低音区吸气还能得到 G 和弦；吸压音便于表现 blues 中的滑音与蓝调音。可以先练这一组 G blues 音阶：

```text
孔位：2吸 → 3吸压半音 → 4吹 → 4吸压半音 → 4吸 → 5吸 → 6吹
音名： G  →    B♭    →  C  →    D♭    →  D  →  F  →  G
音级： 1  →    ♭3    →  4  →    ♭5    →  5  → ♭7  → 高音1
```

第二把位是一个主音位置关系，不等于“只能吹这一条音阶”。大三度、小三度及它们之间的滑音怎样使用，还要结合乐句与和弦。[Lee Oskar 和弦、压音与把位说明](https://leeoskarharmonicas.com/resources/)

第三把位常用于小调色彩演奏，但也不自动等于自然小调：C 调琴自然音以 D 为中心时含 B，而 D 自然小调需要 B♭。因此选对把位后，仍要核对旋律需要哪些音。

## 4. 已知歌曲调，怎样反过来选琴

**知道琴调找演奏调，顺时针走；知道演奏调选琴，逆时针走。** 第一把位不走，第二把位退一步，第三把位退两步。

例如乐队说“这首是 E blues”：

- 第一把位：用 E 调琴。
- 第二把位：从 E 逆时针到 A，用 **A 调琴**。
- 第三把位：从 E 逆时针经过 A 到 D，用 D 调琴。

按常见 blues 演奏调列出速查表，先练第二把位即可：

| 歌曲主音 | 第二把位用琴 | 第一把位用琴 | 第三把位用琴 |
| -------- | ------------ | ------------ | ------------ |
| E        | A            | E            | D            |
| A        | D            | A            | G            |
| G        | C            | G            | F            |
| D        | G            | D            | C            |
| C        | F            | C            | B♭          |
| F        | B♭          | F            | E♭          |
| B♭      | E♭          | B♭          | A♭          |

同一歌曲可以选择不同把位，但容易取得的音、和弦和音色不同；这张表是主音对应关系，不保证每种把位都适合不经技巧处理地吹完整首歌。

## 5. 随和弦走，不必每换和弦就换琴

仍用 C 调琴演奏 G blues：五度圈中的 **C–G–D** 同时对应 IV–I–V，也对应这把琴的一、二、三把位主音。

| 当前伴奏和弦 | 可以先练的落点  | C 调琴孔位  |
| ------------ | --------------- | ----------- |
| G7（I）      | G，强调回到主音 | 2 吸或 6 吹 |
| C7（IV）     | C，回应和弦变化 | 4 吹或 7 吹 |
| D7（V）      | D，准备回到 G   | 4 吸或 8 吸 |

这能帮助你理解不同和弦下的落点，但**整首仍可称为 G 调第二把位演奏**，不必把每次和弦变化都叫作换把位。[口琴制作者 Andrew Zajac 对把位与 I–IV–V 的说明](https://harp.andrewzajac.ca/Positions)

也不要把这些单音落点误当成完整和弦：C 调琴吹 1–3 孔得到 C–E–G，即 C 大三和弦，不是完整 C7；标准自然吹吸也无法直接取得完整 D7。可以吹根音、和弦内音或短句，让吉他、键盘承担完整和声。

练习时先循环上面的 12 小节伴奏，每小节只吹一个对应根音；能稳定跟上和弦后，再加入两三个音的短句，并在句末留白。具体孔位和技巧音可继续查阅 [十孔口琴把位示意图](十孔口琴把位示意图.md)。
