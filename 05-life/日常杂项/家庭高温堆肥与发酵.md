# 家庭高温堆肥与发酵：从 EPP 保温箱到可用的盆栽基质

> 本文介绍家庭植物性厨余的**好氧高温堆肥**，查阅资料日期：2026-10-13。

## 1. 保温箱制作：先做出能通气、排水、测温的箱体

### 1.1 先确定空间和原料是否够用

EPP 是发泡聚丙烯。它能减少散热，热量仍来自微生物分解原料；**箱子本身不产热，也不能把每天一小把菜皮自动变成稳定的高温堆**。[HOTBIN 产品原理与规格](https://hotbincomposting.com/pages/hotbin-composting-basics)，EPP 只减少热量流失，不能替代微生物分解所需的原料、水分和氧气。保温箱的设计目标是让产热不至于快速散掉，同时保留空气进入和湿热气体排出的路径。

对第一次尝试，可把 **100–150 L 左右的容量**作为开始，**前提是有地方翻料，并能在开堆时准备较多混合原料。需要准备一个防水布平铺**，只有 20–40 L 的箱子也能分解有机物，但持续高温更不可靠，冬季尤其如此。不要为了凑满箱子，把厨余在常温密闭桶里积攒到腐臭；干叶和纸板可以干燥储存，厨余及时处理，必要时短期冷藏或冷冻。

箱子放在**通风、避雨、遮阴的室外位置**，留出开盖和倒料空间。室内房间或封闭阳台不适合这种操作。阳台还要考虑湿料重量、排水和邻里气味；保温箱不是承重容器，不宜装满后提着搬。

### 1.2 材料清单

| 材料                           | 用途与选取要求                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------- |
| 有盖 EPP 箱 * 2                | 确认整箱适用的连续使用温度、湿热环境和载荷。一个堆肥，一个熟成。                 |
| 长探针堆肥温度计               | 量程覆盖 0–100℃，探针能到料堆中心；红外测温只能看到表面                        |
| 硬质穿孔托板及支撑             | 架出底部气流与排水空间；材料、支撑和固定件均需适合湿热和湿料重量                 |
| 防虫网、接液盘、架脚           | 通气口防虫、底部不积水；防虫网不是防鼠结构                                       |
| 小铲、口罩手套、混料盆或防水布 | 在箱外混料翻堆，避免铲破内壁；清理切割产生的泡沫碎屑，**注意带口罩手套。** |
| 干叶、碎瓦楞纸板、少量细枝     | 吸水、补碳并维持孔隙，始终留一份备用                                             |
| 无纺布种植袋                   | 给堆肥透气排水                                                                   |

### 1.3 改造的关键是形成完整气流路径

可按下面的纵向结构布置：

```text
有盖防雨，顶部或上侧壁有持续开放的排气口
                  ↑ 湿热空气出去
      留出操作余量，不把料压到盖子下面
      混匀的原料：湿料 + 干料 + 支撑孔隙的粗料
      穿孔托板：承托原料，孔隙不能被糊住
低位进气口 → 底部架空区 → 排液口 → 接液盘
```

一个**未经性能验证的起始布局**：底部架空约 3–5 cm，在架空区对应的两侧各留数个进气孔，上侧壁留排气孔。例如上下两组各 4 个、直径约 15 mm 的孔可作为小规模试验起点；排液口单独设在最低处，不能让接液盘水位堵住进气。孔口加防虫网并定期清理。

孔开得多但内部全是湿泥，仍会缺氧；孔开得过大，冬季又容易散热。**盖子用于保温防雨，进排气口始终保留；不能以封死气孔的办法追求高温。**不要套不透气塑料袋装料，也不要把塑料袋铺在托板上封住气流。

## 2. 堆肥流程：第一次投料与活跃分解

这一步只处理“新料变成停止复热的粗堆肥”：准备原料 → 混匀调湿 → 测温观察 → 按状态翻拌 → 停止加新料。停止复热后，才进入第 4 节的熟成流程。

### 2.1 哪些原料适合新手

| 类别           | 适合的原料                                | 操作注意                                             |
| -------------- | ----------------------------------------- | ---------------------------------------------------- |
| 绿料：相对富氮 | 沥水菜叶、果皮、鲜嫩园艺修剪物（天然植物) | 咖啡渣虽然是棕色，仍按绿料考虑；湿草和咖啡渣容易结团 |
| 棕料：相对富碳 | 干落叶、剪碎的无覆膜瓦楞纸板、短秸秆      | 去掉胶带、订书钉和塑料；纸板遇水不能形成整片隔层     |
| 膨松料         | 少量粗叶柄、短细枝、洁净粗木片            | 提供持久孔隙，分解较慢，后续可筛出再用               |

**初批不放肉、鱼、骨头、奶制品、油脂和高盐熟食，也不放人畜粪便、宠物排泄物、病株、结籽杂草、处理过的木材、来历不明的锯末或塑料制品。** 鸡蛋壳少量压碎可以加入，但不会迅速消失，也不意味着成品能立即高效补钙。家庭堆肥的常规投料边界可参考 [EPA 家庭堆肥指南](https://www.epa.gov/recycle/composting-home)。

### 2.2 投料比例：体积比与碳氮比是两回事

**起步可按松散体积：棕料 2–3 份，绿料 1 份。** 这是便于家庭操作的经验配比；不是干料与厨余的重量比，更不是碳氮比。[EPA 的体积配比建议](https://www.epa.gov/recycle/composting-home)

碳氮比 C:N 指混合原料中碳元素与氮元素的质量比，起始常以约 30:1 为参考。原料含水量、碳氮含量和碳的可利用程度都不同，因此“一桶纸板”和“一桶落叶”不能精确互换。[Cornell 碳氮比计算说明](https://compost.css.cornell.edu/calc/cn_ratio.html)

**供试配的一批原料**，用同一个桶松装量取：

- 20 L 沥水植物厨余和鲜嫩修剪物；
- 30 L 松散碎干叶；
- 10 L 碎瓦楞纸板；
- 若混匀后容易塌成团，再加约 5 L 短细枝或粗木片作为结构材料。

这些体积相加不等于最终料堆体积，混匀和润湿后会收缩。按箱子实际余量调整总量，保留约两成空间用于操作；若原料只有薄薄一层，不应期待按后面的高温日程运行。**示例不是保证达到 C:N=30:1 的检验配方**，最终仍要看湿度、结构、气味和温度。

### 2.3 第 0 天的操作顺序

1. 把大块菜叶、果皮剪成约 2–5 cm；纸板撕碎，不打成糊。适当破碎增加接触面积，保留粗料才能通气。
2. 在箱外把全部原料拌匀，不做厚厚的“厨余一层、纸板一层”。
3. 戴手套抓一把混合料挤压：应像拧过的海绵，湿润、能暂时成团，松手可拨散，最多挤出一两滴水。流水则加干料并重新拌匀；干得散碎则分次喷少量水。
4. 松装进箱，不踩实。表面薄盖碎干叶，减少裸露果皮吸引果蝇；不能让覆盖层堵住排气。
5. 测量并记录中心温度、近边缘温度、室外气温和投料日期，开始按一批管理。

湿度可参考约 40%–60% 的含水范围，手握法仅是粗略判断。适当含水、孔隙和混合比共同作用；材料自带分解微生物，通常无需购买“发酵菌”。[Cornell 家庭堆肥的可控条件](https://www.compost.css.cornell.edu/slideshow/home.slide2.html)

不用为了升温常规添加糖、尿素、石灰或草木灰。首批先观察原料本身的表现，避免同时改变多个变量。若手边有可靠的熟堆肥，少量拌入可以，但它不是必需品，也不能代替原料和空气。

这些条件对应堆肥的基本原理：好氧微生物利用有机物和氧气，释放二氧化碳、水和热量；碳氮比影响食物是否均衡，水分既要支持微生物活动，又不能填满空气孔隙，粗料则帮助氧气进入料堆。日常所说的“发酵”在本文中指这种需要通气的好氧分解，不能按腌菜坛子的方式密闭。若采用 Bokashi 等密闭预处理，它是另一套流程，不能直接套用本文的温度和熟成判断。

### 2.4 为什么要同时看碳氮、水分、空气和保温

| 因素           | 不合适时会怎样                           | 对应操作                                 |
| -------------- | ---------------------------------------- | ---------------------------------------- |
| 碳氮与可分解性 | 木质料过多升温慢；富氮料过多可能出现氨味 | 小幅调整混合物，不凭颜色或单一比例下结论 |
| 含水量         | 太干微生物活动弱；太湿空气进不去         | 少量喷湿或添加干料，每次混匀再判断       |
| 孔隙和供氧     | 打成泥、踩实或湿纸板成片，会形成缺氧区   | 保留粗颗粒，打散结团，保持通风路径       |
| 保温和料量     | 小堆散热快；保温好但产热不足也升不起来   | 原料不足就接受慢堆肥，不靠堵气孔补偿     |

木片的碳不如细碎软质材料容易被利用，所以“补了很多碳”未必能及时吸收过剩氮；水与空气又争夺同一组孔隙。这是不能只看一个配比的原因。[Cornell 水分、碳氮与环境管理](https://www.compost.css.cornell.edu/waterqual.html)

## 3. 看懂温度曲线，按状态操作

### 3.1 预期曲线：反复升降，最终回到环境温度

温度不是越高越好：它反映微生物产热与箱体散热、通风散热之间的平衡。容易分解的物质减少后，产热下降，料堆自然进入缓慢稳定阶段；因此一次升温不能替代后续熟成。

下面是**条件合适时用于安排观察的示意日程**，天数从整批混合投料开始计，温度指料堆内部，不是箱盖附近空气温度。

| 阶段             | 可参考的时间窗口                       | 可能看到的温度与状态                     | 该做什么                                   |
| ---------------- | -------------------------------------- | ---------------------------------------- | ------------------------------------------ |
| 启动             | 第 0–3 天，冷天可更慢                 | 从环境温度升向 30–45℃                  | 检查湿度、进排气和原料量，不要一天翻好几次 |
| 活跃分解         | 第 3 天起，持续数天至数周              | 约 45–60℃，原料逐渐软化、缩小          | 每日测温；观察有无局部过热、结团和异味     |
| 翻拌后的再次升温 | 活跃期中可能重复数次                   | 翻料后暂时降温，随后可能回升             | 把边缘料移入中心，必要时补水或调结构       |
| 活跃期结束       | 快的约 2–6 周，也可能明显更久         | 温度逐步降低，正确调湿翻拌后也不明显复热 | 转入熟成，不再添加新厨余                   |
| 熟成             | 活跃期结束后再留约 4–8 周，必要时延长 | 接近环境温度，气味和质地继续改善         | 保持微湿、透气、防雨，做使用前检查         |

总工期可以先按 **2–4 个月或更久**安排，不能把“几周变黑”当成配土截止日期。RHS 提醒家庭堆肥所需时间差异很大；Cornell 也明确区分快速活跃分解与其后的熟成。[RHS 家庭堆肥](https://www.rhs.org.uk/soil-composts-mulches/composting)、[Cornell 堆肥使用指南](https://cwmi.css.cornell.edu/usersguide.pdf)

```text
温度
60℃           /\       /\
45℃        __/  \_____/  \__
环境温度 ___/                  \_________________
          启动   活跃分解/翻拌       熟成
```

不升温不等于“坏了”，它可能在进行较慢的常温分解；一直降温也不等于“熟了”，缺水、缺氧和料量太少都会产生类似现象。堆温取决于产热与散热的平衡。[Cornell 温度管理](https://compost.css.cornell.edu/Factsheets/FS5.html)

### 3.2 温度管理的动作阈值

对这套自制箱，可把 **45–60℃作为活跃期观察区间**，约 **60–65℃作为加强检查、翻拌散热的提醒区间**；这是偏保守的操作建议，不是所有微生物的精确分界或消毒标准。

- **超过 60℃还在持续上升**：确认测量位置，检查气流并翻拌，必要时暂时减小料堆。
- **达到约 65℃及以上**：及时翻散降温，暂停投料，不能继续封堵孔口保温。
- **接近 70℃或箱体异常**：停止追求高温，把原料在安全、避雨、通风的位置分散冷却，检查箱体和结构。
- 若箱体或附件允许温度更低，以其允许条件为限。

不同指南给出的管理范围有所不同；共同点是过热会抑制分解，不是越热越快。[Cornell 堆肥过程与适宜条件](https://www.compost.css.cornell.edu/Factsheets/FS1.html)

### 3.3 测温和翻料怎么做

首周每天早晚各看一次，稳定后至少每天观察一次。每次测中心和两个不同的近边缘位置，等示数稳定，记录同一时刻的环境温度。不要仅凭插在盖子上的温度计判断整堆情况。

翻料由状态触发：温度过高、有酸臭、局部结团、中心热而边缘长期冷，或活跃期明显降温需要排查时，再整批翻拌。把原料倒到混料盆或防水布上，打散湿团，交换里外位置，再松装回箱。翻后观察次日是否复热；如果还在正常升温且没有异常，不必机械地每天翻。

**中心曾达到 55℃，不能证明整箱已完成病原或杂草种子灭活** ，自制箱有冷点，翻拌覆盖程度与持续时间难以验证，所以本教程不靠“某次温度达标”来放宽原料限制。，

## 4. 熟成流程：从降温到可用于根系

### 4.1 从何时开始计时

只有在**停止加新料、调整湿度并充分翻拌后仍不明显复热**时，才开始按熟成阶段管理。移到带盖但透气的容器，保持微湿、防雨，发现结团再翻松。4–8 周是安排空间和轮换的参考窗口，不是到了日期就自动合格。大学推广资料也将降温后的熟成单独列为阶段。[明尼苏达大学关于堆肥与熟成的说明](https://extension.umn.edu/agriculture/animals-and-livestock/livestock-operations/managing-and-composting-horse-manure)

### 4.2 使用前同时检查这些条件

- 已停止添加生料，整个熟成期没有混入新厨余。
- 调湿、翻拌后连续几天仍接近环境温度，而不是因干透或料太少暂时凉下来。
- 没有明显酸臭、腐臭或氨味，闻起来接近湿土或林地腐殖物。
- 原料大多难以辨认，质地松散；少量木片、果核和蛋壳可筛出。
- 小规模试种没有显示明显抑制。

颜色深、体积小和气味变轻各自都不足以单独证明成熟。RHS 也强调根据成品状态判断，而不是只看历时。[RHS：何时可使用堆肥](https://www.rhs.org.uk/soil-composts-mulches/composting)

### 4.3 家庭试种：看是否抑制发芽和生根

下面是一个**使用前筛查，不是实验室成熟度或卫生检验**：

1. 对照组使用已知正常的育苗基质；试验组使用 8 份同样基质 + 2 份待用堆肥，按体积混合。
2. 两组使用相同容器、同批小白菜或萝卜种子，各播约 10 粒；有条件各做两盆。
3. 放在相同光照温度下，保持相近湿度，观察约 7–14 天的出苗和幼根状态。
4. 若试验组明显少发芽、根短褐变或植株停滞，暂停使用，继续熟成并排查盐分和原料问题。

继续放置未必能解决高盐或污染物问题，不能把所有失败都归因于“再等两周”。试种正常也只说明该比例下没有明显抑制，不能证明不存在病原或化学污染。

## 5. 成品怎样配成“营养土”

### 5.1 熟堆肥是一种配料，不是万能盆土

盆栽基质还要兼顾空气、水和支撑结构。对于来源和盐分未经检测的家庭成品，新手先低比例试用更容易排查问题。不同质量的堆肥适用比例差别很大，并非所有纯堆肥都不能种植；这里采取保守起点。[马里兰大学盆栽基质说明](https://extension.umd.edu/resource/growing-media-potting-soil-containers)

### 5.2 按体积量取的试用配方

以下均为**本文建议的家庭试配起点，不是通用或来源验证过的标准配方**。所有比例都针对已经熟成、通过小试的堆肥。珍珠岩操作前轻微润湿以减少粉尘；椰糠选已处理、低盐产品。

| 用途                   | 10 L 混合物示例                                                | 注意                                                     |
| ---------------------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| 已成株的一般花卉、叶菜 | 8 L 合适的商品盆栽基质 + 2 L 熟堆肥                            | 最简单的首次试配；若原基质已有较多堆肥或肥料，降低添加量 |
| 希望自己配一般盆栽基质 | 5 L 润湿后的低盐椰糠 + 3 L 珍珠岩或合适浮石 + 2 L 熟堆肥       | 只是物理配方起点，不保证营养充足；要按植物和浇水习惯调整 |
| 播种、小苗             | 首批优先使用可靠育苗基质；试验时可用 9 L 育苗基质 + 1 L 熟堆肥 | 幼苗更敏感，先做对照，避免把所有种子押在自制土上         |
| 多肉、仙人掌或喜酸植物 | 先用对应专用基质，自制堆肥少量试用或暂不加                     | 不套用通用“营养土”比例；排水、盐分和 pH 需求不同       |

普通盆栽不建议用黏重园土作为主要配料；花盆底部必须有排水孔。把颗粒拌匀比只在盆底铺一层石子更有助于改善整个基质结构，浇水后仍长期湿黏，就需要减少细料、改善颗粒结构或调整浇水。

### 5.3 肥力、施肥和地栽用法

自制堆肥的氮磷钾没有固定保证值。它能提供有机质和部分养分，但养分释放缓慢，不能默认一季不再施肥；按植物表现、商品基质已有肥力和肥料说明调整，不在新配土里同时叠加多种浓肥。[马里兰大学：堆肥与后续施肥](https://extension.umd.edu/resource/growing-media-potting-soil-containers)

用于已有土壤的菜地或花坛时，可先在局部薄铺约 1–2 cm 熟堆肥，浅混表土或用作表面覆盖，避开贴住茎基部；这是初次试用量，不是年度固定施用量。长期添加要考虑已有肥力，必要时做土壤检测，避免无上限累积。

## 6. 批次轮换：让堆肥和熟成分开

最容易掌握的是“两阶段分开”：

- **A 箱做活跃分解**：新手以批次为单位，记录最后一次加生料的日期。
- **B 箱做熟成**：只接收已完成活跃阶段的料，不加新厨余；一批未成熟前不与成品混装。

A 箱满后停止投料，新厨余需要另一套处理安排，不能为了持续收垃圾而不断打断熟成。商业箱可按其设计连续投料，但自制箱没有经验证的分层流动和取料机制，不能假定“上面进生料、下面取出的一定熟了”。

可复制下面的记录表，每次只作小幅调整，观察后续变化：

| 日期/批次   | 环境温度 | 中心/边缘温度 | 手握湿度 | 气味/渗液 | 翻料或调整内容     | 次日反馈 |
| ----------- | -------- | ------------- | -------- | --------- | ------------------ | -------- |
| 开堆第 0 天 |          |               |          |           | 记录原料和大致体积 |          |

如果长期没有足够原料、没有室外空间，或者无法规律检查，就不必把“稳定高温”作为目标。选择更慢的好氧分解或适合场地的厨余收集方式，比反复向小箱里塞湿料更可控。

## 7. 常见故障：先诊断，再少量调整

| 现象                   | 优先检查                                         | 操作                                                       |
| ---------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| 几天后仍与环境温度接近 | 探针是否测到中心、料量、湿度、孔隙，最后再看配料 | 太干先调湿，太湿先松料；排除这些后，才考虑少量增加鲜嫩绿料 |
| 酸臭、臭鸡蛋味、料发黏 | 湿团、积液、堵孔或装得过实                       | 暂停投料，整批翻松，加干料与结构料，清理排液路径           |
| 刺鼻氨味               | 富氮原料过多，也可能有碱性添加物                 | 补适量细碎棕料并混匀，不加石灰或草木灰“除味”             |
| 中心热，边缘长期冷     | 冷点和分布不均                                   | 翻拌交换位置；不能只记录最高温                             |
| 翻后不再升温           | 先排除太干、缺氧、体积缩小                       | 条件适宜仍不复热，才考虑进入熟成                           |
| 大量渗液               | 原料未沥水、雨水进入或料堆压实                   | 控制水源，补干料，及时处理积液，不能靠接液盘长期兜底       |
| 果蝇、虫多             | 裸露果皮、积液或网孔破损                         | 混入湿料，薄覆干料，清理积液并修补网口，不往堆里喷杀虫剂   |
| 纸板、木片很久不消失   | 块头太大或木质化程度高                           | 筛出回下一批；不要为少数木片无限延长整批周期               |

**渗滤液不是现成的“液体肥”或成熟堆肥茶**。不喷叶、不接触可食部分、不排入雨水口；少量可用干料吸收后回堆，并重新调整湿度。持续大量出液应先解决工艺问题，清理时戴手套。

翻料避免扬尘，开盖时不把脸贴近料堆，操作后洗手。健康活跃的堆不应持续散发强烈腐臭，有臭味先排查湿度与供氧。

如果温度、气味和湿度长期无法稳定，先停止继续投料，把料堆分散到安全、避雨、通风的位置；不要靠封死气孔、添加强氧化剂或升温设备“硬救”。
