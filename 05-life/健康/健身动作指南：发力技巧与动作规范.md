# 健身动作指南：发力技巧与动作规范

配套计划：[一周运动健身计划](一周运动健身计划.md)。适用于当前“上肢优先、下肢减量”的前三个月。

本指南讲动作，不额外增加训练量。组数、次数、休息及渐进安排以计划为准；同类替代动作选一种，不把每种变式都做一遍。腿举、分腿蹲、弓箭步及第四个月才考虑的髋铰链练习不属于当前动作清单。

## 1. 所有动作通用的执行原则

- **先设置，再选重量。** 第一次请教练现场检查座椅、靠垫、转轴和安全限位；器械结构不同，以设备说明和实际关节轨迹为准。记录适合自己的设置。
- **稳定不等于僵硬。** 胸廓大致位于骨盆上方，腹部轻收紧，像准备承受轻轻一推；不要吸瘪腹部，也不必全程用最大力绷紧。
- **呼吸连续。** 新手通常在推、拉、抬起等用力阶段呼气，回程吸气。核心练习保持轻度腹压并继续呼吸，不用长时间憋气完成次数。
- **动作速度可控。** 可用约 1–2 秒用力、2–3 秒回程学习动作；这是控制提示，不是必须卡秒的标准。不要砸配重、弹震或借惯性。
- **活动范围以控制和无痛为界。** 不要为了“全程”强行压到关节极限，也不要靠缩短幅度掩盖重量过大。
- **区分发力与疼痛。** 肌肉用力、疲劳不等于关节刺痛、夹痛、麻木或脚踝不稳。出现后者即停止该动作；伤踝次日肿胀增加，应退阶并联系康复人员。[AAOS 足踝康复说明](https://www.orthoinfo.org/recovery/foot-and-ankle-conditioning-program)
- **感觉是提示，不是考核。** 拉类动作中手臂参与正常，没出现明显“背部泵感”不代表动作无效；用轨迹、稳定性、规范次数和长期表现共同判断。
- **肩胛骨可以自然移动。** 划船回程允许受控前伸，肩推时允许随手臂上举转动，不把“全程夹紧、压低肩胛”套用到所有动作。
- **伤踝也可能在上肢训练中受力。** 取放哑铃、上下凳、拉取高处把手和蹬地借力都要考虑。当前优先稳定座位、胸托与器械；不要用左脚跳起抓把手。

### 每组开始前的四个问题

1. 座位、靠垫、插销和器械是否稳固？
2. 能否在不蹬地、不扭身的情况下开始第一下？
3. 能否在全组使用相近幅度，并控制回程？
4. 还保留计划要求的余力吗？上肢通常 2–3 次，下肢 3–4 次；姿势开始失控就结束该组。

## 2. 上肢推类动作

### 2.1 器械胸推

**主要训练：** 胸大肌，三头肌和肩前束协同。

**设置与动作：**

1. 调座椅，让把手起点约在胸部中段高度；背部和臀部贴靠，双脚舒适支撑。
2. 手腕大致与前臂成一直线，肘在身体两侧稍向下，不强行张成水平的“一字形”。
3. 呼气将把手向前推，直到手臂接近伸直，不用猛顶肘关节。
4. 缓慢回到胸前，肩前侧无夹痛、上臂不过度后拉的位置。

**发力提示：** “胸部把上臂向前合拢，手腕稳住。”肩胛自然贴靠，不为追求幅度把肩头向前顶出。

**常见错误与纠正：** 手腕后折→降低重量、把握点放稳；耸肩或腰部大幅拱起→调整座椅、收回肋骨；脚猛蹬地→减重。

**自检：** 最后几次仍能保持臀部贴座、脚部不借力，左右把手同步前进。

### 2.2 上斜器械胸推／上斜哑铃卧推

**主要训练：** 胸大肌，偏重锁骨部参与，肩前束和三头肌协同。

**器械版：** 按设备规定调整座椅，使起点在上胸附近，手腕与前臂对齐；沿器械轨迹向前上方推，回程不让肩前侧被过度拉伸。其余规则同胸推。

**哑铃版：**

1. 使用稳固上斜凳，约 15–30°可作为尝试起点，不必追求大角度。
2. 由教练协助安全取放哑铃，当前不使用需要伤踝用力蹬地的上凳方法。
3. 背部、臀部稳定贴靠，哑铃位于胸部两侧，肘在手腕下方附近。
4. 向上推起，左右保持可控，不必碰撞哑铃；慢慢下放到肩部舒适的位置。

**发力提示：** “推起上臂，不把肩头顶向耳朵。”

**错误与自检：** 上斜过大变成近似肩推、哑铃下放过深、为了推起而抬臀，均应调整。无法安全取放重量时选器械，不把搬哑铃当作训练的一部分。

### 2.3 坐姿器械肩推

**主要训练：** 三角肌，尤其前束，同时涉及中束和三头肌。

**设置与动作：** 背部贴靠；把手起点约在肩部附近，根据器械和肩部舒适度调整。肘略在身体侧面前方，手腕不塌。呼气沿轨迹上推，肩胛随手臂自然上旋；在不抬肋骨、不拱腰的范围内伸展手臂，再控制下放。

**发力提示：** “上臂向上推，肋骨留在骨盆上方。”不强行把肩胛全程往下压。

**常见错误：** 靠腰后仰换取幅度、脚蹬地、下降到肩部明显夹痛的位置。先减重或缩小无痛范围；仍不适则暂停，请教练检查器械是否适合。

**自检：** 从侧面看，腰背形态没有随每次推起明显改变，呼吸连续。

## 3. 上肢拉类动作

### 3.1 胸托划船：双臂水平拉

**主要训练：** 背阔肌、菱形肌、斜方肌中部等，肩后束与肘屈肌参与。

**设置与动作：**

1. 调胸垫和座位，使胸部有支撑、手臂伸出时能握住把手，不用探身够取。
2. 胸部贴垫，颈部自然，双脚不蹬地。
3. 呼气将肘向后带，把手拉向下胸或上腹附近，具体服从器械轨迹。
4. 拉到上臂接近躯干或略过躯干、肩部仍舒适的位置即可；回程允许肩胛受控前伸，但胸部不离垫。

**发力提示：** “肘往后走，胸留在垫上。”手稳握把手，避免只靠手腕和手臂猛拉。

**常见错误：** 抬胸离垫、后仰甩起、为了夹背把肘过度拉到身后。降低重量，不追求最大挤压感。

**自检：** 来回都能停住，不靠躯干运动推动配重。

### 3.2 高位下拉：垂直拉

**主要训练：** 背阔肌等背部肌群，肘屈肌协同。

**设置与动作：**

1. 调大腿压垫，让大腿稳定但不被压痛；把手选择舒适的中立握或正握，握距不必很宽。
2. 先安全拿到把手再坐稳；够不到时请人协助，不跳起抓握。
3. 身体可轻微后倾并保持，腹部轻收紧，肘向身体两侧下方移动。
4. 把手下拉至上胸附近或自己的无痛终点，不要求一定碰胸。
5. 缓慢回程，手臂上伸、肩胛自然上转，不突然被拉离座位。

**发力提示：** “肘向肋骨靠近，把上臂拉下来。”

**常见错误：** 颈后下拉、每次大幅后仰变划船、用腰甩重量、为了触胸而折手腕。减重并固定躯干角度。

**自检：** 下拉和回程时脚都不蹬地，颈部没有前伸去迎接把手。

### 3.3 单臂海豹划船／胸托单臂划船

**主要训练：** 单侧背部和肘屈肌；可练习两侧独立控制，但胸托减轻了躯干稳定需求，不能代替专门的抗旋转训练。

**设置与动作：**

1. 优先选独立手柄胸托器械；海豹划船使用专用平卧凳，确保哑铃有足够下降空间。不要用杠铃片或松散箱子把凳子垫高。
2. 胸部、腹部按凳面设计得到稳定支撑；双腿舒适放置，不靠伤脚抵住地面维持平衡。若无法稳定摆位就换器械。
3. 弱侧先做，肘向后拉，胸廓和骨盆不跟着转动。
4. 慢慢伸回手臂，肩胛可小幅前伸，躯干仍贴靠。
5. 强侧使用相同重量和次数，不额外加做。每侧 3 组按计划计为每侧 3 组，不合并成某侧 6 组。

**发力提示：** “只有这侧手臂和肩胛移动，身体朝向不变。”

**错误与自检：** 为多拉几厘米扭腰、抬胸、拉哑铃时撞击凳架，均应减重或调整器械。另一只手可以轻扶支撑，但不要用力拉凳子借力。

## 4. 肩部与手臂辅助动作

### 4.1 坐姿侧平举：哑铃／器械

**主要训练：** 三角肌中束等肩部肌群。

**动作：** 坐稳，哑铃置于两侧，肘轻弯并基本保持弯曲程度；上臂在身体侧面略偏前的平面抬起，到接近肩高或更低的舒适范围后，慢慢下降。器械版将靠垫放在设备要求的上臂位置，按轨迹抬起。

**发力提示：** “肘带着上臂向两侧抬。”拇指可自然朝前或略朝上，不刻意做“小拇指高、倒水”的动作。

**常见错误：** 甩身体、每次明显增加屈肘、用耸肩代替抬臂。先减重；允许肩胛自然运动，不强行把肩膀压住。

**自检：** 轻重量也能缓慢回程，颈部不因动作持续紧绷，肩部无夹痛。

### 4.2 反向蝴蝶机

**主要训练：** 肩后束，肩胛周围肌群协同。

**动作：** 面向靠垫坐稳，使把手约在肩部高度或略低，按器械要求握把；肘微弯且角度基本不变，将上臂向两侧后方打开，到上臂接近躯干所在平面、肩部舒适的位置，控制合拢。

**发力提示：** “把上臂向两边展开，胸留在垫上。”肩胛可自然靠拢，不追求极限夹背。

**常见错误：** 大幅弯肘做成划船、向后挺胸、把手拉到身后很远。减小重量和幅度。

**自检：** 手臂走弧线而不是把肘贴向身体拉，胸垫始终有稳定接触。

### 4.3 绳索弯举／弯举机

**主要训练：** 肱二头肌、肱肌等肘屈肌。

**坐姿绳索版：** 用稳定座椅面对低位滑轮，确保绳索路径不碰脚踝、凳脚或身体。握把后坐稳，上臂靠近体侧；手腕平直，弯肘抬起把手，到无需抬肩或把肘向前顶的位置，再慢慢伸回。

**弯举机版：** 调座位，使上臂按要求贴靠垫、肘部与器械转轴大致匹配，避免垫边压迫肘窝；按相同屈肘原则完成。

**发力提示：** “上臂安静，前臂弯过来。”

**常见错误：** 抬肩、后仰、折腕、伸肘末端撞击限位。减重，保持平滑运动。

**自检：** 能在任意位置短暂停住，臀部不离座。周四若站姿做会压迫伤踝，仍用坐姿或器械版。

### 4.4 绳索下压／臂屈伸机

**主要训练：** 肱三头肌。

**坐姿绳索版：** 请教练协助安排稳定座位与高位滑轮距离，使绳索不会贴脸、座位不会滑动，且上臂能自然靠近体侧。握直杆或绳索，肘弯曲起始；保持上臂大致不动，将肘伸直到接近伸直，再控制屈肘回程。绳索末端可自然分开，不必用力掰腕。

**器械版：** 选择座位稳定、肘伸展轨迹舒适的三头肌器械；有上臂垫时按设计对齐转轴，不强行统一为某一种姿势。若使用下压式臂屈伸机，不把肩拉到过深的后伸位置。

**发力提示：** “伸直肘，不靠整个身体往下压。”

**常见错误：** 耸肩、甩上臂、俯身用体重压下、脚蹬地。减少重量；若坐姿绳索无法稳定设置，直接选合适器械，不临时搭凳架。

**自检：** 主要发生的是肘关节伸屈，肩部无顶痛，回程配重不落砸。

## 5. 少量下肢训练

以下动作均保留 3–4 次余力，符合康复许可且无痛才做。坐姿不等于伤踝完全不受力，靠垫位置和上下器械过程同样需要检查。

### 5.1 坐姿腿伸展

**主要训练：** 股四头肌。

**设置与动作：** 调整靠背使膝关节大致对齐器械转轴，坐稳、臀部不滑动；小腿垫放在设备要求的小腿下段，不能直接压在疼痛的踝部或脚背。轻握扶手，伸膝抬起小腿，到接近伸直但不猛顶的位置，再慢慢屈膝返回。

**发力提示：** “大腿前侧把膝盖伸直，臀部留在座位上。”脚踝保持舒适，不用刻意大力勾脚或绷脚。

**常见错误：** 踢甩重量、抬臀、为了完成次数缩短后半程、用脚踝顶垫。先减重并重新设置。

**自检：** 膝部轨迹稳定、踝部无压痛；靠垫无法避开伤处时跳过，不能靠忍痛完成。

### 5.2 坐姿腿弯举

**主要训练：** 腘绳肌。

**设置与动作：** 膝与器械转轴大致对齐，大腿固定垫贴合但不过度压迫；下方滚垫位于设备规定的小腿后侧位置，避免压住伤踝或疼痛的跟腱区域。背部和臀部贴靠，屈膝将小腿向座位下方带，缓慢伸回，不突然放开。

**发力提示：** “大腿后侧把小腿折回来。”不是用脚尖勾住滚垫。

**常见错误：** 抬臀、前后挪动身体、用力绷脚找杠杆。降低重量，确保固定垫合适。

**自检：** 小腿移动时大腿和骨盆稳定；腘绳肌用力正常，踝部疼痛不正常。

### 5.3 臀推机／地面臀桥

**主要训练：** 臀大肌，其他髋伸肌协同；仍需要足部承重，不是伤踝完全卸载动作。

**臀推机：** 请教练设置背垫、安全扣和髋部压垫，压垫放在器械指定的髋部区域，不直接压腹部。双脚平稳放置，间距约髋宽；抬髋时膝盖朝脚尖方向，肋骨不过度上翻，髋伸直到躯干与大腿接近连线即可，再控制下降。顶端小腿接近竖直可作为调脚位置的起点，不必硬凑角度。

**地面臀桥：** 仰卧屈膝，双脚平放；呼气、轻收腹后抬髋，到肩—髋—膝接近连线，停一下再下降。初期徒手，不直接在腹部堆放哑铃。

**发力提示：** “臀部抬起骨盆，别用腰把胸顶起来。”全脚掌舒适受力，不只压脚跟，也不抬脚尖强行找臀感。

**常见错误：** 腰部过伸、膝内扣、踮脚、顶端追求过高。减小幅度；如果腿后侧抽筋，先停止，重新评估脚位和负荷。

**自检：** 足跟不抬、脚踝无疼痛或不稳，腰背没有明显挤压感。任一版本不耐受就跳过本周臀推，不以单腿臀桥替代。

### 5.4 髋外展机

**主要训练：** 臀中肌等髋外展肌群，具体参与随坐姿和器械变化。

**动作：** 背部贴靠、骨盆保持朝前，膝部外侧按设计贴靠垫，脚舒适支撑；把大腿向两侧打开到可控位置，慢慢合回。不要强行开到器械最大角度。

**发力提示：** “大腿向外打开，骨盆不摇摆。”

**常见错误：** 大幅前后倾身、弹起重量、靠脚向外蹬踏板。先减重，不用换姿势追求更强灼烧感。

**自检：** 躯干稳定、髋外侧用力，膝和踝没有扭转或压痛。

## 6. 核心稳定训练

### 6.1 坐姿 Pallof press：抗旋转推举

**主要训练：** 躯干抵抗旋转的控制能力，手臂负责保持把手位置。

**设置与动作：**

1. 稳定训练凳侧对拉力器，滑轮调至坐姿胸部附近高度。凳子不应在拉力下滑动。
2. 双手把把手放在胸前，身体朝前、双脚舒适支撑；先用很轻重量。
3. 呼气将手向正前方推，骨盆和胸廓保持朝前，肩膀不被拉偏。
4. 前方停约 1 秒并保持呼吸，再收回；换另一侧面对器械重复。

**发力提示：** “把手会被拉向侧面，身体不要跟着转。”

**常见错误：** 身体反向倾斜抵消拉力、双脚猛蹬、把肩推得耸起来。降低配重或缩短手臂伸出距离。

**自检：** 从正面看鼻子、胸骨和骨盆方向基本不变；不要主动左右转动完成次数。

### 6.2 死虫：正式训练与家庭轻量版

**主要训练：** 躯干抗伸展控制、四肢协调。

**动作：** 仰卧，头颈放松，双臂指向上方，髋膝约弯曲 90°。呼气轻收腹，使腰背维持舒适稳定，不随腿伸出而越来越拱。缓慢伸出一侧手臂与对侧腿，到还能稳定腰背的位置，再返回换侧。手脚不必贴到地面。

**发力提示：** “手脚走远，躯干留住。”

**退阶：** 先只动一只手，或保持屈膝、单腿小幅下降；比同时伸直四肢更容易控制。家庭版幅度和次数更少，不做至疲劳。

**常见错误：** 憋气、腰明显拱起、颈部抬起、伸腿太低。缩短动作距离；脚踝自然放松，不刻意绷直脚尖。

**自检：** 能边动作边缓慢呼气，左右速度相近，腰背无疼痛。NASM 将该动作定位为抗伸展核心练习，可参考其[死虫示范](https://www.nasm.org/resource-center/exercise-library/dead-bug)。

## 7. 家庭活动度与可选俯卧撑

### 7.1 侧卧胸椎旋转

**目的：** 练习上背部温和旋转，不是用力扭腰。

**动作：** 侧卧、髋膝舒适弯曲，头下可垫薄枕，双膝叠放；双臂向前伸。上侧手臂缓慢向身后打开，胸廓跟着转，视线可随手移动；下肢和骨盆尽量稳定，再回到起点。

**提示：** “打开胸口，膝盖留在原处。”手背不必碰地，呼气时温和转动。

**错误与调整：** 膝盖翻开、用腰硬扭、压肩触地。减小范围；脚踝之间可垫软垫，避免伤侧受压，任何侧卧姿势不适则换体位或跳过。

### 7.2 仰卧温和髋部活动：屈膝小幅外打开合

原计划未指定具体动作，此处提供一种可选执行方式，不新增训练量。

**动作：** 仰卧、双膝弯曲、脚舒适平放；保持骨盆平稳，一侧膝盖小幅向外打开，再收回，换侧。脚部随动作自然微调，不能把伤脚固定后强行转动膝盖。

**提示：** “髋部轻轻转动，骨盆不跟着滚。”目的是轻松活动，不追求大幅拉伸。

**错误与调整：** 膝盖压到地面、腰部翻转、足部卡住产生扭力。如果伤踝不适，可由双手托住该侧大腿，让脚离地并放松，再做小幅髋活动；仍不适就跳过。

**自检：** 髋部无夹痛，脚踝无扭转或牵拉感。

### 7.3 俯卧撑：墙面、高台、跪姿

**主要训练：** 胸部、三头肌和肩前束，躯干参与稳定。

**通用动作：** 双手略宽于肩，手指舒适展开；肘朝身体斜后方弯曲，不横向张成一条直线。身体作为整体靠近支撑面，吸气下降、呼气推回；顶端允许肩胛自然向前滑，不强行夹背。

| 版本           | 设置与要点                                               | 脚踝考虑                             |
| -------------- | -------------------------------------------------------- | ------------------------------------ |
| 墙面俯卧撑     | 手扶墙，脚离墙距离以能控制身体为准，头—躯干—腿大致成线 | 仍需双脚支撑；伤踝不适则不做         |
| 稳固高台俯卧撑 | 用固定台面，台面越高通常越容易；不得用滑动桌椅           | 不自动比墙面更适合伤踝，检查承重耐受 |
| 跪姿俯卧撑     | 膝下垫软垫，头—躯干—大腿大致成线；脚趾不勾地承重       | 脚踝自然放松，脚背也不应被压痛       |

**发力提示：** “胸部与髋部一起下降，再一起推起。”

**常见错误：** 塌腰、翘臀、只低头不弯肘、肘外张过大。选择更容易的版本，减少次数。

**自检：** 全组姿势相近，脚踝不疼；没有任何无痛版本时跳过，不为补胸部容量忍痛。

## 8. 踝活动与扶物平衡：仅限已获许可的内容

扭伤的部位、严重程度和康复阶段尚未具体记录，因此以下是执行原则与条件示例，不是新增康复处方。动作方向、承重程度、次数和保持时间按医生或康复师要求执行。AAOS 也强调应由专业人员帮助选择适合的练习。[足踝康复指南](https://www.orthoinfo.org/recovery/foot-and-ankle-conditioning-program)

### 8.1 已获许可的踝活动

**若已获准做踝泵：** 坐着或仰卧支撑小腿，让足部不承重；缓慢勾脚、放回或轻轻向下指，均停在许可的无痛范围。小腿不跟着大幅摆动，不用手强掰。

**提示：** “轻轻移动脚，不追求最大角度。”不要因为踝泵无痛，就自行加入内外翻、弹力带阻力、大幅画圈或提踵；这些需要单独确认是否适合当前伤情。

**自检：** 过程中无痛，之后及次日没有新增肿胀或不稳；不满足时停止并反馈康复人员。

### 8.2 已获许可的扶物平衡

**设置：** 在平整、防滑地面，手扶牢固台面，按康复要求穿鞋或支具。先采用专业人员指定的双脚或偏重心站姿；只有获准单腿负重后才尝试单脚版本。

**动作：** 视线朝前，膝轻微放松，躯干大致直立；双脚版温和调整重心，单脚版仅在许可范围内减少另一脚支撑。手随时提供足够帮助，不用强撑证明平衡能力。

**提示：** “身体稳住，脚掌舒适贴地，手可以帮忙。”

**常见错误：** 膝锁死、足部明显内外翻、摇晃时跳步补救、过早闭眼或站软垫。增加手部支撑或退回双脚；不稳时直接落下另一脚。

**自检：** 无疼痛、无打软腿，能安全结束动作，不以险些摔倒作为进阶标准。

## 9. 训练前快速查阅

| 动作               | 最值得记住的一句提示             |
| ------------------ | -------------------------------- |
| 胸推／上斜胸推     | 手腕稳，背臀贴靠，不靠脚蹬起重量 |
| 肩推               | 手臂上举，肋骨不抬，肩胛自然转动 |
| 胸托划船           | 肘向后，胸留在垫上               |
| 高位下拉           | 肘向下，身体角度不来回变         |
| 单臂海豹／胸托划船 | 手臂拉，胸廓和骨盆不转           |
| 侧平举             | 上臂向两侧抬，不甩、不倒水       |
| 反向蝴蝶机         | 上臂展开，肘角基本不变           |
| 弯举／下压         | 动肘关节，不摆整个身体           |
| 腿伸展／腿弯举     | 骨盆稳，靠垫不压伤踝             |
| 臀推／臀桥         | 抬髋不顶腰，脚踝不适就跳过       |
| 髋外展机           | 大腿打开，骨盆不摇摆             |
| Pallof press       | 手向前，身体不跟着拉力转         |
| 死虫               | 手脚移动，腰背形态保持稳定       |
| 胸椎旋转           | 打开胸口，骨盆不跟着翻           |
| 仰卧髋活动         | 小幅活动，不扭伤脚               |
| 俯卧撑             | 胸髋同时移动，选伤踝无痛的版本   |
| 踝活动／扶物平衡   | 只做获准内容，不自行加难度       |

如需拍视频请教教练，可在不拍到他人的前提下，用轻重量分别拍正侧面几次动作；重点看身体是否借力、关节轨迹是否稳定，不根据视频自行判断韧带是否恢复。
