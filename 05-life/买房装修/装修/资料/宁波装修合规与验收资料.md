# 宁波装修合规与验收资料

> 用途：为 110㎡左右住宅的半包装修计划提供可核对的法规、标准和本地管理入口。本文只记录应在签约、开工、隐蔽验收和竣工时核对的事项；具体以物业、主管部门和合同约定的现行版本为准。
>
> 核查时间：2026-10-30。网页访问受限时保留官方检索入口，执行前应由业主或设计师再次确认现行版本。

## 1. 国家层面的装修管理底线

### 1.1 住宅室内装饰装修管理办法

- 来源：住房和城乡建设部，建设部令第 110 号《住宅室内装饰装修管理办法》官方发布入口：[中国政府网法规库](https://www.gov.cn/zhengce/content/2008-03/28/content_4723.htm)；可在住建部官网以“建设部令第110号”检索。
- 对本项目的直接动作：开工前向物业办理装修登记；提交装修方案、施工期限和施工人员信息；涉及拆改主体结构、承重墙、楼板、阳台等内容时，先取得原设计单位或有资质设计单位的书面确认及相关审批；不得擅自改变外立面、燃气管线和公共设施。
- 合同动作：把物业允许施工时段、押金、垃圾清运方式、公共区域保护、电梯使用、违规罚责写入开工交底单，避免工头口头承诺无法追责。

### 1.2 建筑装饰装修工程质量验收标准

- 来源：住房和城乡建设部现行工程建设国家标准《建筑装饰装修工程质量验收标准》GB 50210-2018，标准信息可通过住建部标准定额司和国家标准全文公开系统检索：[国家标准全文公开系统](https://openstd.samr.gov.cn/)。
- 现场动作：按“基层—隐蔽—面层—成品保护”分段验收；墙地面空鼓、开裂、平整度，门窗安装，吊顶和隔墙固定，饰面砖粘结，涂饰观感，橱柜和木作收口分别留存照片和整改记录。
- 交付动作：不以“看起来差不多”替代实测；将验收结果、整改期限和复验结果写入项目日志并由业主、施工方工头、设计师、项目经理四方确认。

### 1.3 住宅装饰装修工程施工规范

- 来源：国家标准 GB 50327-2001《住宅装饰装修工程施工规范》，可通过国家标准全文公开系统检索：[国家标准全文公开系统](https://openstd.samr.gov.cn/)。
- 现场动作：水电管线走向、给排水试压、卫生间防水、闭水试验、吊顶内设备检修、木材防潮和成品保护必须在封闭前验收；施工规范属于过程控制依据，合同中应约定“隐蔽工程未经签字不得封闭”。

## 2. 浙江省和宁波本地应核对的入口

### 2.1 浙江省住宅室内装饰装修验收

- 来源：浙江省地方标准 DB33/T 1132-2017《住宅室内装饰装修工程质量验收规范》，标准信息与文本入口：[浙江省地方标准公开平台](https://db33.gov.cn/)；也可在浙江省市场监督管理局官网检索标准编号。
- 对本项目的直接动作：把标准中涉及给排水、电气、防水、墙地面、门窗、吊顶、橱柜和室内环境的验收项目转成《分项验收单》；每个隐蔽项目至少记录日期、位置、实测值、照片、整改闭环和四方签名。
- 处理原则：地方标准与合同约定不一致时，采用现行强制性工程建设规范和合同中更严格的可执行条款；不把验收标准的建议值改写成无法证明的“保证零问题”。

### 2.2 宁波市建筑垃圾和装修垃圾

- 来源：宁波市人大常委会法规数据库，检索《宁波市建筑垃圾管理条例》：[宁波人大法规数据库](https://www.nbrd.gov.cn/)。住建、城管部门的建筑垃圾处置公告以宁波市住房和城乡建设局、宁波市综合行政执法局官网为准。
- 开工前动作：向物业确认小区装修垃圾临时堆放点、清运预约方式、收费口径、时间窗口和电梯保护要求；要求清运方提供计费凭据，装修合同中明确费用承担和超期责任。
- 现场动作：装修垃圾与生活垃圾分开；不得把砂浆、油漆、涂料、胶黏剂直接倒入下水；保持公共走道、电梯轿厢和消防通道畅通；拍照记录清运前后状态。

### 2.3 宁波燃气和管线改动

- 来源：宁波市人大常委会法规数据库，检索《宁波市燃气管理条例》：[宁波人大法规数据库](https://www.nbrd.gov.cn/)。燃气企业改管、停气、通气和验收以所在区域燃气经营企业的官方要求为准。
- 红线动作：燃气表、立管、阀门和燃气设施不得由普通装修工人私自拆改；需要移位、改管或新增燃气设备时，先由燃气企业现场确认并施工，取得验收凭证后再封闭橱柜或吊顶。
- 设计动作：橱柜深化前锁定燃气表、热水器、烟道、地漏和插座位置；预留检修和通风空间，避免先做柜体后发现燃气验收无法通过。

## 3. 材料环保、消防与用电

### 3.1 室内装饰材料环保

- 来源：国家强制性标准 GB 18580-2017《室内装饰装修材料 人造板及其制品中甲醛释放限量》及配套材料标准，标准信息入口：[国家标准全文公开系统](https://openstd.samr.gov.cn/)。
- 采购动作：板材、地板、胶黏剂、涂料、壁纸等要求品牌、型号、等级、检测报告和批次信息；送货验收拍摄外包装、合格证和批号；合同写明“替代材料须经业主书面确认”。
- 现场动作：材料进场先验收再切割；发现包装破损、受潮、批次不符或报告与实物不符，立即隔离并在日志中记录，不得默认接受。

### 3.2 消防和电气安全

- 来源：国家标准 GB 55037-2022《建筑防火通用规范》及 GB 50303-2015《建筑电气工程施工质量验收规范》，标准信息入口：[国家标准全文公开系统](https://openstd.samr.gov.cn/)。
- 现场动作：强弱电分离，回路和漏保标识清楚；卫生间、厨房、阳台等潮湿区域按设计设置保护；配电箱、吊顶内接线盒和阀门保留检修条件；不把电线接头埋在墙内或用不合格接线方式替代接线盒。
- 验收动作：记录回路绝缘、接地、漏电保护器和插座相位检测结果；大功率电器在方案阶段确定独立回路和容量，避免入住后反复改线。

## 4. 必须进入项目台账的合规节点

| 节点 | 必须留存的证据 | 未完成时的处理 |
|---|---|---|
| 物业报装前 | 装修申请、方案、施工人员信息、押金和垃圾清运规则 | 不进场，不拆改 |
| 拆改完成 | 原结构照片、拆改范围确认、物业/设计书面意见 | 未确认不得继续封闭 |
| 水电隐蔽 | 回路图、管线照片、压力/通水/绝缘/接地记录 | 未签字不得封槽、封板 |
| 防水 | 材料批次、涂膜照片、闭水起止时间和楼下检查记录 | 漏水先整改复验 |
| 燃气改动 | 燃气企业施工和验收凭证 | 不得封柜或通气使用 |
| 材料进场 | 品牌型号、数量、合格证、检测报告、批次照片 | 隔离、退换或书面让步接收 |
| 竣工 | 分项验收单、整改清单、设备说明和保修联系人 | 未闭环不结清尾款 |

## 5. 使用说明

本页不替代设计图、物业规定、燃气企业验收和现行法律文本。每次签约或采购前，项目负责人应打开上述官方入口核对标准版本和本地执行口径；发现链接失效时，以主管部门官网按标题和编号检索的最新文件为准。
