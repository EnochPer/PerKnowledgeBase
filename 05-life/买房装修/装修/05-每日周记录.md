# 装修每日与周记录

> 每天收工前 5 分钟填日卡；每周日填复盘。问题详情进 04，决策进 01，变更进 02；这里只写编号、照片和截止时间。

## 1. 日卡（每天 5 分钟）

```markdown
## YYYY-MM-DD（周X） 第__天

- 阶段 / 天气 / 到场人员：
- 今日完成 3 项：T-__ / 位置 / 照片编号
- 明日计划 3 项：T-__ / 前置条件 / 负责人
- 未来 1–3 天材料/设备：名称 / 数量 / 到货日 / 责任人
- 新问题：P-__ / 严重度 / 责任人 / 截止（详情见 04）
- 需业主决策：D-__ / 截止（详情见 01）
- 一句话风险：
```

填写规则：

- 每项任务写编号、位置、照片编号；没有照片的任务不算完成。
- 新问题当天编号并写入 04；日卡只留编号和截止。
- 新决策当天写入 01；新变更当天写入 02。
- 不写长故事、不贴大段聊天记录；需要时引用照片编号。

## 2. 周复盘（每周日 20 分钟）

```markdown
## 第__周复盘（YYYY-MM-DD ～ YYYY-MM-DD）

- 计划完成 / 实际完成 / 偏差天数：
- 本周关闭问题：P-__、P-__
- 未关闭问题：P-__（责任人/截止）、P-__（责任人/截止）
- 本周返工：次数 / 原因 / 费用影响
- 预算变化：变更单 C-__ / 金额 / 工期影响
- 下周关键路径 3 条：
- 下周必须到位的材料/人员/设备：
- Top 3 风险：风险 / 影响 / 责任人 / 截止
- 待业主决策：D-__ / 截止
- 四方周确认：业主__ / 工头__ / 项目经理__ / 设计师__ / 日期__
```

## 3. 群消息模板

```text
【YYYY-MM-DD/第__天】阶段：…
进展：T-__ + 位置 + 照片编号
问题：P-__ + 方案 + 责任人 + 截止
材料：未来 1–3 天到位项
待决策：D-__ + 截止
风险：一句话
```

## 4. 使用规则

- 日卡由工头填，项目经理补问题/决策/风险；业主只看编号和证据。
- 全屋定制增项记 06 的 K-xxx，问题记 04 的 P-xxx；套餐、测量、安装见 [06-全屋定制.md](06-全屋定制.md)。
- 每周日把未关闭高/中问题逐条过一遍，更新 04 和 README 总控台。
- 四方签字只放在隐蔽、分项验收、变更、付款和周会，不每天签。
- 没有编号、照片、实测或签字的“已完成”，不作为付款和转序依据。
