## 每周节奏

- **周一**：项目经理交本周关键路径、未来 1–3 天材料/人员、需业主决策事项；业主确认后发群。
- **每日收工前**：工头填 5 分钟日卡；项目经理补问题编号、责任人和截止时间。
- **节点**：隐蔽、分项、竣工按 04 验收；未通过不封闭、不转序、不付款。
- **周日**：复盘计划/实际、问题关闭率、预算变化、下周关键路径；更新总控台。
- **付款前**：核对 02 的付款条件、04 的验收/整改、03 的票据和到货记录。

## 业主管理原则

1. **只认证据**：任务编号、照片、实测值、签字、票据；口头“没问题”不算。
2. **固定节奏**：日卡、周会、节点验收；不靠临时催问和现场盯人。
3. **一个决策窗口**：所有决定进 01 决策记录，群里只认文字；不接受私下分别承诺。
4. **付款绑验收**：本阶段完成、验收通过、问题关闭、资料齐全，才付款。
5. **问题当天定责**：编号、责任人、截止时间、复验人；不隔夜、不带病转序。
6. **让专业人先提方案**：项目经理交关键路径和资源计划，工头交班组/工艺/自检；业主只设门槛、截止和验收标准。
7. **用抽查验证真实性**：随机核对材料批次、隐蔽照片原图、关键尺寸、工人到场；每个关键节点至少抽查一次。
