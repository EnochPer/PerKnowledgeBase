## 2. 三层验收

> 验收优先级：安全/结构/防水/燃气/强弱电/环保 > 功能尺寸与设备可安装 > 隐蔽可追溯 > 表面观感 > 软装搭配。

- **物资进场**：核对品牌、数量、型号、规格、批次、合格资料；不符先隔离，不得先用后补。
- **工序工艺**：按图纸、合同、样板和实测值检查；工头自检 → 项目经理复检 → 设计师确认 → 业主确认关键节点。
- **工序衔接**：确认基层、完成面、尺寸、养护、材料、工具和成品保护；项目经理主持交接，不具备条件不转序。

| 角色 | 在验收中签什么 | 什么时候签 |
|---|---|---|
| 工头 | 自检记录、施工照片、材料使用 | 每道工序完成、封闭前 |
| 项目经理 | 复检结论、整改安排、交接单 | 隐蔽/分项/转序/付款前 |
| 设计师 | 图纸/节点/效果/材料适配 | 关键节点、变更、收口 |
| 业主 | 关键节点确认、变更/付款确认 | 隐蔽、验收、变更、付款 |

## 3. 分阶段检查清单

### 3.1 拆改/砌墙

- [ ] 图纸、物业批准、现场标记一致；承重墙、公共立管、燃气、烟道未动 — 证据：批准文件 + 拆改前照片
- [ ] 新砌墙拉结、防裂处理；门洞/设备洞按最终尺寸留设 — 证据：节点照片 + 实测
- [ ] 拆改垃圾装袋、公共区保护、货梯/清运合规 — 证据：照片 + 清运单
- [ ] 拆改完成面与后续完成面厚度核对 — 证据：剖面/实测
- [ ] 隐蔽管线位置拍照存档 — 证据：带尺/日期照片

### 3.2 水电

- [ ] 回路按负荷分组；厨房、卫浴、空调、锅炉独立回路 — 证据：回路图
- [ ] 强弱电分离；线管弯曲、线盒高度、回路标识 — 证据：照片 + 绝缘/通断
- [ ] 给水试压、排水通水、坡度检查 — 证据：试压记录 + 照片
- [ ] 冷热水方向、角阀、设备接口与安装图一致 — 证据：照片 + 尺寸
- [ ] 封槽前点位复核；封槽/找平/吊顶前各一次隐蔽确认 — 证据：四方签字
- [ ] 配电箱、漏保、接地、插座相位 — 证据：检测记录

### 3.3 防水/闭水

- [ ] 防水范围/高度按设计/物业要求；管根、阴阳角、地漏加强 — 证据：照片
- [ ] 闭水 24–48 小时；起止时间、液面变化、楼下顶面 — 证据：记录 + 楼下确认
- [ ] 回填材料和工法按合同；不用建筑垃圾随意回填 — 证据：材料单 + 照片
- [ ] 防水保护层施工，后续工序不破坏 — 证据：交接单
- [ ] 渗漏整改后复验 — 证据：复验记录

### 3.4 泥工

- [ ] 排版、起铺点、对缝、坡度、收口 — 证据：排版图 + 照片
- [ ] 瓷砖色号、批次、试铺 — 证据：批次照片
- [ ] 空鼓、平整、阴阳角、倒角、开孔 — 证据：空鼓锤 + 实测
- [ ] 地漏排水、门槛石、过门石、完成面 — 证据：泼水试验 + 照片
- [ ] 切割边和不同批次收口 — 证据：照片
- [ ] 成品保护 — 证据：照片

### 3.5 木工/吊顶

- [ ] 吊顶检修口、灯孔、排烟/排风口、窗帘盒、设备检修位 — 证据：定位图 + 照片
- [ ] 龙骨、吊杆、固定、防火、防潮 — 证据：隐蔽照片
- [ ] 石膏板接缝、转角、不同材料交接防裂 — 证据：节点照片
- [ ] 柜体、门套、墙面收口和伸缩缝 — 证据：照片 + 尺寸
- [ ] 封板前拍照并确认可维修 — 证据：四方签字

### 3.6 油工

- [ ] 基层含水率、空鼓、开裂、阴阳角 — 证据：实测 + 照片
- [ ] 腻子不厚批掩盖墙面问题；打磨、除尘 — 证据：过程照片
- [ ] 底漆/面漆遍数、色号、环保资料 — 证据：材料单 + 照片
- [ ] 色差、流坠、透底、开裂、污染保护 — 证据：验收记录
- [ ] 成品保护和修补 — 证据：照片

### 3.7 门窗/安装

- [ ] 逐窗编号、洞口尺寸、开启方向、五金、窗纱分离 — 证据：编号图 + 实测
- [ ] 型材系列、结构深度、隔热条、玻璃配置、4SG 资料 — 证据：截面/标识/报告
- [ ] 窗框固定、发泡/填缝、内外密封、排水孔、窗台坡 — 证据：照片 + 淋水
- [ ] 分窗拼接、转角、下框连续密封；不倒灌 — 证据：淋水记录
- [ ] 门/柜/橱柜/卫浴/灯具/家电安装水平、牢固、密封、可维护 — 证据：验收单（柜体按 06 §8）
- [ ] 交叉安装的成品保护和损坏赔偿 — 证据：交接单

### 3.8 竣工

- [ ] 分项验收单、整改清单全部关闭 — 证据：清单
- [ ] 通水、通电、通气、排水、地暖、锅炉调试 — 证据：调试记录
- [ ] 环保检测、合格证、质保资料 — 证据：资料包
- [ ] 保洁、钥匙、余料、保修联系人 — 证据：交接单
- [ ] 尾款释放条件满足 — 证据：02 付款表

## 7. 业主关键节点追问 8 条

1. 今天计划完成什么？实际完成什么？偏差多少？
2. 今天哪几名工人施工？姓名、工种、电话、区域？
3. 有没有新增、取消或替换的材料、工艺或费用？变更单编号是多少？
4. 现场材料是否与合同和采购台账一致？包装、型号、批次、资料在哪？
5. 未来 1–3 天的材料、设备、人员、机具到位了吗？谁负责补齐？
6. 今天哪些工序已验收？谁自检、谁复检、谁签字？
7. 有没有未验收就封槽、封板、回填、铺贴或遮挡的部位？
8. 今天发现哪些问题/返工/风险？编号、责任人、截止时间、复验时间？
